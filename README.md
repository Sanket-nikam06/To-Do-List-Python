# To-Do-List-Python
A simple command-line To-Do List application written in Python that helps you manage your tasks efficiently.

## Features

- View all tasks with their completion status
- Add new tasks to the list
- Remove tasks from the list
- Mark tasks as completed
- User-friendly command-line interface
- Visual status indicators (✅ for completed, ❌ for pending tasks)

## Getting Started

### Prerequisites

- Python 3.x installed on your system

### Running the Application

1. Clone or download this repository
2. Navigate to the project directory
3. Run the application:
   ```
   python todo.py
   ```

## Usage

The application provides a simple menu-driven interface with the following options:

1. **View Tasks**: Displays all your tasks with their completion status
2. **Add Task**: Add a new task to your list
3. **Remove Task**: Remove an existing task by its number
4. **Mark Task as Done**: Mark a task as completed
5. **Exit**: Close the application

### Example Usage

1. To add a task:
   - Select option 2
   - Enter your task description

2. To mark a task as complete:
   - Select option 4
   - Enter the task number

3. To remove a task:
   - Select option 3
   - Enter the task number
